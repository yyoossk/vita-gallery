VitaShell の FTP でスクリーンショットを見る

PS Vita の ux0:picture/SCREENSHOT の中にある写真 (jpg / bmp) を、フォルダ別に表示します。表示した写真はダウンロードと削除ができます。

  1. PS Vita で VitaShell を開きます
  2. SELECT ボタンを押して FTP を開始します (画面に IP アドレスが表示されます)
  3. 表示された IP アドレスを下に入れて「読み込む」を押します

PC と PS Vita が同じ Wi-Fi (同じネットワーク) につながっている必要があります。VitaShell の FTP を止めると接続できなくなります。
